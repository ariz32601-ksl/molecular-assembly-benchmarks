# Exact Molecular Assembly Indices and Compression Baselines for 695,133 Natural Products (COCONUT 2.0)

**Author:** Chun Tang ([ORCID: 0009-0008-4128-2071](https://orcid.org)) · Kunpeng Sovereign Lab

Deterministic Rust/Python audit pipelines, schema-governed SQLite/Parquet data dictionary, and SHA-256 verification manifests for scale-controlled evaluation of exact Molecular Assembly (`MA`) against 1D/2D compression baselines across **695,133 COCONUT 2.0 natural products** (`N = 626,131` pinned exact cohort) and **5,653 DrugBank compounds**.
