# Molecular Assembly Indices for the COCONUT Paper 3 Cohort

Chun Tang · Kunpeng Sovereign Lab · [ORCID](https://orcid.org/0009-0008-4128-2071)

This repository accompanies Paper 3, a study of molecular assembly indices and compression baselines for 626,131 COCONUT records. The production run ledger contains 695,133 records; the study uses a pinned subset of 626,131 with exact assembly indices that met its inclusion criteria.

**Status:** Paper 3 has been submitted to ChemRxiv and is in moderation. The SQLite and Parquet files are not yet available. The release will include a data dictionary and checksums.
